إضافة متصفح خفيفة تمنحك زرًا مباشرًا لحظر أو كتم حسابات X من داخل التغريدة. تعمل محليًا، بلا حساب، وبلا تتبع أو إرسال بيانات.

## لماذا One Click Block Twitter؟

- **نقرة واحدة:** اختر الحظر أو الكتم مرة واحدة، ثم نفّذ الإجراء مباشرة من كل تغريدة.
- **غير مهتم:** أخفِ المنشور وامنح توصيات X إشارة مباشرة من زر مستقل بجوار زر الحساب.
- **لوحة تحكم:** شغّل أو أوقف One Click Block Twitter وأزراره بشكل مستقل، وراجع عدد مرات الحظر والكتم و«غير مهتم» المخزنة محليًا.
- **واجهة عربية وإنجليزية:** تتبع لغة المتصفح وتدعم واجهات X العربية والإنجليزية.
- **استجابة واضحة:** تتزامن الأيقونة والتسمية مع الإجراء المختار، وتُستعاد التغريدة كما كانت إذا فشل التنفيذ.
- **أداء مناسب للتمرير:** مستمع أحداث واحد، تخزين مؤقت للإعدادات، ومعالجة مستهدفة لتغيّرات DOM.
- **خصوصية محلية:** لا توجد خوادم أو تحليلات أو اتصالات خارجية.

## الهوية

### تنظيف روابط المنشورات عند النسخ

تزيل الإضافة تلقائيًا معاملات التتبع `a` و`s` و`t` و`ref_src` و`ref_url` و`utm_*` من روابط منشورات X وTwitter عند النسخ، بما فيه زر «نسخ الرابط». تبقى معاملات الرابط الأخرى كما هي، ولا تحتاج الميزة إلى صلاحية قراءة الحافظة. تعمل تلقائيًا داخل صفحات X وTwitter بصورة مستقلة عن مفاتيح الحظر والكتم.

بعد تحديث الإضافة، أعد تحميل تبويبات X المفتوحة لتفعيل التنظيف.

يجمع شعار One Click Block Twitter بين درع وشق قطري يرمزان إلى تحكم المستخدم وإيقاف الضوضاء غير المرغوبة. تفاصيل الاستخدام والألوان والنبرة موثقة في [`BRAND.md`](BRAND.md).

## التثبيت اليدوي

نزّل حزمة الإضافة وفك ضغطها، ثم:

### Chrome / Edge

1. افتح `chrome://extensions/` أو `edge://extensions/`.
2. فعّل **وضع المطور**.
3. اختر **تحميل إضافة غير معبأة**.
4. حدّد مجلد One Click Block Twitter الذي يحتوي `manifest.json`.

### Firefox 140+

1. افتح `about:debugging#/runtime/this-firefox`.
2. اختر **تحميل إضافة مؤقتة**.
3. حدّد `manifest.json` من مجلد One Click Block Twitter.

## التطوير والتحقق

يتطلب Node.js 22 أو أحدث، ولا توجد اعتمادات تشغيل خارجية:

```bash
npm test
npm run check
```

الاختبارات تغطي حقن الزر، مزامنة الإعدادات، دفعات DOM، منع اختيار إجراءات التراجع، واتجاه الواجهة. يفحص الأمر الثاني JavaScript وManifest والترجمات والموارد المحلية.

## الخصوصية

One Click Block Twitter لا تجمع أو ترسل أي بيانات. الإذن الوحيد غير المرتبط بالموقع هو `storage` لحفظ اختيار الحظر أو الكتم محليًا.
