إضافة متصفح لإدارة خطّك الزمني على X وتويتر: حظر أو كتم الحسابات وإخفاء المنشورات بنقرة واحدة، وتنظيف روابط المنشورات من التتبع عند النسخ. تعمل محليًا دون حساب إضافي أو اشتراك أو جمع بيانات.

## الميزات

- **حظر أو كتم بنقرة:** اختر الإجراء من لوحة الإضافة واستخدم الزر بجوار قائمة المنشور.
- **غير مهتم:** زر مستقل لتنفيذ «غير مهتم» على المنشور.
- **تحكم مستقل:** أوقف أزرار الخط الزمني معًا أو تحكم بكل نوع على حدة، مع الاحتفاظ بتفضيلاتك.
- **إحصاءات محلية:** عدادات للحظر والكتم وإخفاء المنشورات مع إمكانية تصفيرها. التسجيل والتصفير يمران بطابور واحد لتجنب تعارض الكتابة.
- **عربية وإنجليزية:** تدعم واجهتي X العربية والإنجليزية. لوحة التحكم تتبع لغة المتصفح مع العربية كخيار احتياطي.
- **معالجة على دفعات:** تتوقف مراقبة المنشورات عند إخفاء التبويب أو تعطيل الأزرار وتستأنف عند العودة.

## تنظيف الروابط تلقائيًا

عند نسخ رابط منشور داخل X أو تويتر، بما فيه زر **نسخ الرابط**، تُزال معاملات التتبع المعروفة: `a` و`s` و`t` و`ref_src` و`ref_url` و`utm_*`.

قبل التنظيف:

```text
https://x.com/RT_com/status/2115682103388160134?a=IFSg4JJx7rPAIubkMF0&s=20
```

بعد النسخ:

```text
https://x.com/RT_com/status/2115682103388160134
```

تبقى معاملات الرابط الأخرى كما هي. يقتصر التنظيف على روابط المنشورات في النطاقات المدعومة، ويعمل بصورة مستقلة عن مفاتيح أزرار الحظر والكتم، دون صلاحية قراءة الحافظة.

## التثبيت والتحديث

### Firefox 140+

للتثبيت الدائم والتحديثات، استخدم [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/hajb/).

للتجربة المؤقتة من المصدر:

1. نزّل ZIP من [Releases](https://github.com/2-sa/hajb/releases/latest) وفك ضغطه.
2. افتح `about:debugging#/runtime/this-firefox`.
3. اختر **تحميل إضافة مؤقتة** وحدد `manifest.json` من المجلد المستخرج.

التحميل المؤقت ينتهي عند إعادة تشغيل Firefox. ملف GitHub ليس حزمة Firefox موقّعة للتثبيت الدائم.

### Chrome / Edge

1. نزّل ZIP من [Releases](https://github.com/2-sa/hajb/releases/latest) وفك ضغطه.
2. افتح `chrome://extensions/` أو `edge://extensions/`.
3. فعّل **وضع المطور** ثم اختر **تحميل إضافة غير معبأة**.
4. حدّد المجلد الذي يحتوي `manifest.json`.

بعد تحديث الإضافة، أعد تحميل تبويبات X المفتوحة لتفعيل الكود الجديد.

## الخصوصية والصلاحيات

الإضافة لا تجمع أو ترسل بيانات المستخدم، ولا تستخدم تحليلات أو خدمات خارجية. تُحفظ الإعدادات والعدادات محليًا بصلاحية `storage`. تعمل سكربتات المحتوى داخل صفحات `x.com` و`twitter.com` والنطاقات الفرعية المطابقة فقط.

تنظيف الروابط يعالج النص عند نسخه داخل الصفحة ولا يقرأ حافظة النظام. الحظر والكتم و«غير مهتم» تتفاعل مع واجهة X نفسها؛ تبقى اتصالات الموقع المعتادة جزءًا من عمل X.

## التطوير والتحقق

المشروع يستخدم JavaScript وHTML وCSS مباشرة، دون تجميع أو تصغير أو اعتمادات خارجية. يتطلب تشغيل الفحوصات Node.js 22 أو أحدث:

```sh
npm test
npm run check
```

على PowerShell، إذا منعت سياسة التنفيذ `npm.ps1`، استخدم `npm.cmd` بدلًا من `npm`.

تغطي الاختبارات حقن الأزرار ومزامنة الإعدادات وتغيّرات DOM وتنظيف الروابط وتسلسل تحديث العدادات والتعافي من فشل الحفظ. يفحص الأمر الثاني صياغة السكربتات وManifest والترجمات والموارد المحلية.

تعتمد إجراءات المنشورات على بنية واجهة X وتسمياتها وقد تحتاج تحديثًا إذا تغيّرت. الاختبارات تحاكي DOM ولا تغني عن التجربة داخل المتصفح. اكتمال الضغط في الواجهة لا يثبت وحده قبول خوادم X للإجراء.

```text

```

## الإصدارات وتجهيز الحزمة

الإصدار الحالي **3.1.5** يحدّث الاسم والوصف بالعربية والإنجليزية. أضيف تنظيف الروابط وإصلاح الإحصاءات في **3.1.4**. التفاصيل في [Releases](https://github.com/2-sa/hajb/releases).

لإصدار نسخة جديدة، حدّث `package.json` و`manifest.json` معًا ثم ادفع وسمًا مطابقًا مثل `v3.1.6`. يشغّل [Release workflow](.github/workflows/release.yml) الفحوصات ويجهّز ZIP وينشره في GitHub Releases. التشغيل اليدوي يتطلب اختيار وسم إصدار.

لتجهيز حزمة من المصدر باستخدام `zip`:

```sh
zip -r hajb-v3.1.5.zip manifest.json background.js content popup icons _locales
```

تُحزم الملفات دون تحويل. الصور والتوثيق والاختبارات لا تدخل في حزمة الإضافة. النشر على Firefox Add-ons منفصل عن GitHub Releases. نصوص التقديم في [ملف المتجر](output/store/README.md).

## الترخيص

جميع الحقوق محفوظة لمالك المستودع. إتاحة المصدر على GitHub لا تمنحه ترخيصًا مفتوحًا.

الإضافة مستقلة وغير تابعة لشركة X أو معتمدة منها.
