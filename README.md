# إضافة الحظر السريع لـ تويتر (OneClickBlock) 🛡️

الإضافة الأسرع، والأكثر كفاءة، والأذكى لحظر أو كتم الحسابات المزعجة في منصة تويتر (إكس) بنقرة زر واحدة وبدون أي تأخير!

## المميزات العبقرية (Enterprise Features) 🚀

- **الإخفاء الفوري اللحظي:** التغريدات تختفي من أمامك في جزء من الثانية دون ترك أي أثر، مع الاعتماد على أحدث حيل التخفي البرمجية لتجنب تعارضات React الخاصة بتويتر.
- **استهلاك معدوم للذاكرة (0% RAM bloat):** بفضل تطبيق تقنية **تفويض الأحداث (Event Delegation)** المتقدمة، تعتمد الإضافة على مستمع وحيد فقط للصفحة كلها. يمكنك التمرير لملايين التغريدات دون أن تستهلك الإضافة أي موارد إضافية!
- **سرعة قراءة الإعدادات (Instant Caching):** لا تتصل الإضافة بقواعد البيانات مع كل تمريرة كما تفعل الإضافات العادية، بل تقرأ الإعدادات فوراً من الذاكرة العشوائية.
- **التوافق التام مع سياسات الأمان (Manifest V3 100%):** لا تستخدم الإضافة أي مصادر أو خطوط خارجية، وتعتمد بالكامل على خطوط النظام الأصلية، مما يمنحها أماناً مطلقاً واعتمادية فورية في متجر الإضافات.
- **متعددة اللغات بذكاء (Native i18n):** واجهة الإضافة تترجم نفسها تلقائياً للغة جهاز المستخدم (عربي/إنجليزي)، بينما يقوم "قناص الأزرار" بالبحث عن الكلمات المناسبة في تويتر بذكاء بغض النظر عن لغة التصفح.
- **الدقة المتناهية لحماية الأبرياء:** تستهدف الإضافة بدقة الرابط الفعلي لاسم المستخدم عبر `a[role="link"]` لضمان عدم حظر أي شخص بريء تمت الإشارة إليه بالخطأ في التغريدة.

## طريقة التثبيت اليدوية (Developer Mode) 🛠️

قم بتنزيل ملف الـ ZIP للإضافة وقم بفك الضغط عنه في مجلد، ثم اتبع الخطوات حسب متصفحك:

### 🌐 لجوجل كروم ومايكروسوفت إيدج (Chrome / Edge):
1. اذهب إلى صفحة الإضافات `chrome://extensions/` (أو `edge://extensions/`).
2. قم بتفعيل **"وضع المطور" (Developer mode)** من الزاوية العلوية.
3. اضغط على زر **"تحميل إضافة غير معبأة" (Load unpacked)**.
4. اختر المجلد الذي قمت بفك الضغط فيه.

### 🦊 لمتصفح فايرفوكس (Firefox):
1. اذهب إلى صفحة `about:debugging#/runtime/this-firefox`.
2. اضغط على زر **"تحميل إضافة مؤقتة" (Load Temporary Add-on...)**.
3. ادخل إلى مجلد الإضافة، واختر ملف `manifest.json`.

## الهيكلة الهندسية (Architecture) 🏗️

```text
OneClickBlock/
├── _locales/           # ملفات الترجمة القياسية (عربي وإنكليزي)
│   ├── ar/messages.json
│   └── en/messages.json
├── content/            # قلب الإضافة النابض والمدمج بالكامل
│   ├── content.js      # منطق المراقبة وتفويض الأحداث الذكي
│   └── content.css     # التنسيقات والأنيميشن النظيف
├── icons/              # الأيقونات بجميع المقاسات
├── popup/              # الواجهة العصرية للإعدادات (Glassmorphism)
│   ├── popup.html
│   ├── popup.js
│   └── popup.css
└── manifest.json       # تعريف الإضافة لمتجر كروم (Manifest V3)
```
